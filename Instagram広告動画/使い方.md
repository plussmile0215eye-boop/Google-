# Instagram広告 動画の使い方

写真がなくてもそのまま使える、文字が動くタイプの縦長動画（1080×1920・9:16）です。リール・ストーリーズ広告にそのまま使えます。

| ファイル | 長さ | 内容 |
|---|---|---|
| はじめての方へ_15秒_縦長.mp4 | 15秒 | 熊本市東区で → パリジェンヌ・マツエク・眉毛WAX → 個室 → 駐車場7台 → 当日予約OK → ＋Smile.（Googleクチコミ5.0・予約ボタンへ） |
| メンズ眉毛WAX_10秒_縦長.mp4 | 10秒 | 眉が整うと印象が変わる → メンズ眉毛WAX → 個室で気軽に → ＋Smile.（駐車場7台・当日OK） |

## 広告にするまで

1. 動画をスマホに保存する
2. Instagramで「リール」として投稿する（音楽はこのときInstagramの音源から付けられます。動画自体は無音です）
3. 投稿したリールを開いて「投稿を宣伝」→ 設定は [Instagram広告案](../Instagram広告案.md) の「7. 設定のしかた」のとおり

- 音楽は、広告に使える音源（「Meta Sound Collection」など）を選んでください。流行りの曲でも広告にすると使えない場合があります
- 「Googleクチコミ5.0」は、広告を出す時点で5.0のままか確認してください
- 大事な文字は、Instagramのボタンや説明文とかぶらない真ん中あたりに置いています
