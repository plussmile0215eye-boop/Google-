# Instagram広告 画像テンプレートの使い方

[Instagram広告案](../Instagram広告案.md) の広告A・B・C用の画像です。

| ファイル | サイズ | 使う広告 |
|---|---|---|
| A_パリジェンヌ_フィード用 | 1080×1350（4:5） | 広告A（写真2枚のビフォーアフター） |
| A_パリジェンヌ_リール・ストーリーズ用 | 1080×1920（9:16） | 広告A（リールの表紙・最後のカット、ストーリーズ） |
| B1〜B5 | 1080×1350（4:5） | 広告B（カルーセル5枚。B4はメニューで写真なし・そのまま使えます） |
| C_メンズ眉毛_フィード用 | 1080×1350（4:5） | 広告C |
| C_眉毛WAX_写真入り_完成 | 1080×1350（4:5） | 広告C（写真入りの完成版。そのまま投稿できます） |

- **〜_見本.png** … 完成イメージ（しましまの部分に写真が入ります）
- **〜_重ねる用.png** … 写真の部分が透明になった画像。写真の上に重ねて使います

## 写真の入れ方（スマホ・無料アプリ「Canva」の場合）

1. Canvaで「Instagram投稿（4:5）」または「Instagramストーリー」の新しいデザインを開く
2. 施術写真をアップロードして、透明の窓の位置に合わせて置く（ビフォーは左／上、アフターは右／下）
3. 「〜_重ねる用.png」をアップロードして、ページいっぱいに広げて一番上に置く
4. 写真をタップして、大きさと位置を窓に合わせる（目もとが窓のまん中に来るように）
5. ダウンロード → Instagramに投稿 →「投稿を宣伝」

※ 他のアプリ（Phonto、PicsArt、Instagramのストーリーズの「画像を追加」など）でも、「写真の上に重ねる用のPNGをのせる」流れは同じです。

## 注意

- 写真はお客さまに **広告に使う許可** をもらったものだけにしてください
- ビフォーとアフターは同じ明るさ・同じ角度で撮り、加工はしないでください
- リール用は、上下にInstagramのボタンや文字がかぶるため、大事な文字は真ん中寄りに配置しています
