# パリジェンヌ お客様ビフォーアフター（Instagram用）

## 画像の作り方

1. お客様の写真を `写真/` フォルダに入れる
   - ビフォー → `before.jpg`、アフター → `after.jpg`（png でもOK）
   - 目もとのアップを**横長**で撮ると枠にきれいに収まります（ビフォー・アフターは同じ角度・同じ明るさで）
2. このフォルダで `node render.js` を実行
3. 次の2枚ができます
   - `パリジェンヌビフォーアフター_投稿_完成.png`（1080×1350・フィード投稿用）
   - `パリジェンヌビフォーアフター_ストーリーズ_完成.png`（1080×1920）

お客様ごとに分けたいときは、`写真/aさん_before.jpg`・`写真/aさん_after.jpg` のように名前を付けて `node render.js aさん` と実行してください（出力ファイル名にも名前が付きます）。

写真が入っていないときは、枠の位置がわかる「サンプル」画像ができます。

### 掲載前のチェック
- お客様から**掲載の許可**をもらっている（画像の下に「掲載許可をいただいています」と入ります）
- 目もとだけのトリミングなど、お客様が特定されにくい切り取り方になっている
- 加工・フィルターをかけていない（ビフォー・アフターで同じ条件）
